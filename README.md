## Featured Projects

Here is an overview of the technical projects I have developed. You can explore the source code and detailed reports directly within this profile:

### CLaRion — CLaRa Parallelization
* **Technologies:** Cython, OpenMP, Python, RAG architectures.
* **Objective:** Low-level optimization of a Retrieval-Augmented Generation (RAG) pipeline featuring encoder pretraining and joint training.
* **Results:** Achieved substantial performance speedups over NumPy ($2.91\times$ for forward inference, $8.4\times$ for generation, and $2.45\times$ for training).

### Dynamic ViT — Efficient Vision Transformer
* **Technologies:** PyTorch, Transformers, LoRA, Hugging Face.
* **Objective:** Designed an ultra-low-capacity Dynamic Vision Transformer incorporating adaptive token pruning.
* **Results:** Reached 37% top-1 accuracy on ImageNet-1k with only 1.8M parameters and 0.12 GFLOPs/image.

### Linguistic Analysis & Contrastive NLP
* **Technologies:** NLP, Contrastive Learning, MultiNCE, POLAR.
* **Objective:** Conducted semantic and syntactic parsing of political manifestos to isolate structural complexity metrics.
* **Method:** Combined density modeling with POLAR-based sentiment extraction techniques and contrastive loss frameworks.

### LLM-Powered Phishing Detection
* **Technologies:** Scikit-Learn, PyTorch, Phi-2, Prompt Engineering, Streamlit.
* **Objective:** Built an automated tool for phishing message classification and synthetic phishing content generation.
* **Results:** Developed a Naive Bayes baseline ($98.5\%$ accuracy) coupled with a Phi-2 LLM fine-tuned via LoRA.
