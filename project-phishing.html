Research Overview

The project investigates how large language models can generate increasingly convincing phishing emails while simultaneously evaluating the robustness of classical detection systems.


A Naive Bayes classifier was trained as a baseline detector before introducing an adaptive ReAct loop where generated emails were continuously evaluated and reinjected into future prompts.


The second stage focused on fine-tuning Phi-2 using QLoRA 4-bit quantization, allowing efficient training while preserving strong language generation capabilities.
